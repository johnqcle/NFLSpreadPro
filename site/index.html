How it works

Each team's rating averages a score-based rating with a per-play efficiency (EPA) rating seeded from 2025. That rating is blended 50/50 with the line, adjusted for division games, spreads of 7+, and favorite rest edge, plus each team's prior cover record (always included). Each backtest week uses only earlier games.

Research, not betting advice. The backtest has hindsight in how the model was chosen, and the samples are small. The only picks posted in advance (Weeks 5–6) went 5-2-1.
